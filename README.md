REQUIRED ORIGINAL
Use the unmodified Japanese Redump dump identified by this entry:
http://redump.org/disc/65407/

The game is distributed as 30 separate BIN tracks plus a CUE sheet.
These patches require that split-track layout. Do not apply them to a merged
BIN, an ISO, a CHD, another region/version, or an already patched track.
No game images or BIOS files are included. Supply your own matching dump.
The Redump link identifies the required disc; it is not a game download.

BOTH PATCHES ARE REQUIRED
Strider Hiryuu (T-ENG) (Track 02).xdelta
Strider Hiryuu (T-ENG) (Track 30).xdelta

Each patch applies to its matching original track. Neither patch is a
standalone translation. All other 28 tracks remain unchanged.

HOW TO APPLY WITH DELTA PATCHER
1. Make a working copy of the entire original game folder, including all
   30 BINs and the CUE. Keep an untouched backup of the original dump.
2. Close/unload the game in your emulator.
3. In Delta Patcher's patch-application mode, choose the working copy of
   "Strider Hiryuu (Japan) (Track 02).bin" as the original file, and choose
   "Strider Hiryuu (T-ENG) (Track 02).xdelta" as the patch. Apply it with
   checksum validation enabled.
4. Repeat with the ORIGINAL Track 30 BIN and the Track 30 patch.
5. Keep the resulting BIN filenames exactly as referenced by the CUE.
   The patch filenames contain T-ENG; this does NOT mean the BIN filenames
   should be renamed. If your patcher creates separately named output files,
   put them in the working game folder under the original BIN filenames.
6. Keep all 30 tracks together. The original CUE layout remains valid.
   Load the CUE in your emulator, rather than opening an individual BIN.
7. Start from a fresh boot. Saves made with an older build can contain old
   code and graphics in memory and are not a reliable test of this release.

PLAYING THE TRANSLATION
An Arcade Card-capable setup is required. For emulation, enable Arcade Card
support and configure a compatible System Card BIOS. A Super CD-ROM setup
without the Arcade Card expansion is insufficient.

English text and subtitles are provided while the original Japanese voices
are retained. The original Japanese title artwork is retained. Track 01's
spoken audio-CD warning also remains in Japanese.

OPTIONAL SHORTCUTS
On the options screen (the screen with difficulty and lives):
- Infinite health and lives: Up, Up, Up, Down, Down, Down, Left, Right,
  Left, Right. Release each direction between presses. A chime confirms it.
- Alternative protection shortcut: hold buttons I and II, then press Select.
- Stage selector with protection: hold buttons I and II, then press Run.
  Release the buttons after activation. The selector initially targets the
  final stage. These refer to console buttons, not specific keyboard keys.
Protection is optional and must be activated again after a fresh reset/boot.

TROUBLESHOOTING
- A checksum error means the patch and source do not match. Verify the exact
  original track against the hashes above. Do not disable checksum checking
  to force a patch onto a mismatched source.
- If the game does not boot, confirm that both patches were applied and that
  every FILE entry in the CUE points to an existing BIN in the same folder.
- If subtitles are missing, verify both translated output hashes, enable the
  Arcade Card, and start fresh without loading an older savestate.
- Report problems with the emulator/version, stage and scene, output hashes,
  and whether the issue occurs after a fresh boot. A screenshot and a save
  immediately before the problem are useful.
